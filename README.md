# AnnaChakra

AI-powered food demand forecasting, waste management,
and surplus food redistribution platform for institutional kitchens.

## Core Features

- Kitchen-specific food demand forecasting
- Serving-based meal preparation recommendations
- Historical consumption tracking
- Adaptive forecasting and model retraining
- Computer vision-assisted leftover food logging
- Food safety eligibility screening
- Intelligent NGO matching
- Kitchen-managed food delivery
- Impact analytics and administration

## User Roles

- Kitchen Staff
- NGO Manager
- Administrator

## Technology Stack

- Frontend: React, Vite, Tailwind CSS
- Backend: FastAPI
- Database: PostgreSQL
- ORM: SQLAlchemy
- Migrations: Alembic
- Machine Learning: XGBoost, Scikit-learn
- Computer Vision: MobileNetV2, TensorFlow

## Repository Structure

- frontend/ - Web application
- backend/ - REST API and business logic
- ml/ - Model training and inference
- docs/ - Project documentation
